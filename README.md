# Робот-копилка "Попрошайка"/=0
> ИНТЕРАКТИВНЫЙ робот в коробке " ДАЙ ПАЗЯЗЯ" созданный для выпрашивания монеток!
---
## 😺 Главный инженер-тестировщик
* **ИМЯ**: Пушинка
* **Должность**: Шеф-эксперт по нажатию фольгированных кнопок и выдаче мурчания
---
## 📦 Корпус и кибер-дизайн
* **Материал**: Высокопрочный крафтовый гофрокартон.
* **Интерфейс**: Надпись **"ДАЙ ПАЗЯЗЯ"** для работы со спонсорами и стикер **"ОСТОРОЖНО КРУТОЙ ПОДАРОК"**.
---
## 🛠️ Технические Характеристики
* **Мозг**: Arduino UNO R3 (ATmega328P)
* **Датчик**: Кнопка- замыкатель из фольги (`INPUT_PULLUP`)
* **Анимация**: Сервоприврод SG90 (механическая лапка)
* **Аудиосистема**: Зуммер-Пищалка
**ИТАК, СЛУШАЙ СЮДА. КАК ПАШЕТ ЭТО ВСЁ НА САМОМ ДЕЛЕ...**
## ⚙ Алгоритм работы
Когда **Пушинка** наступает лапкой на фольгу, контакты замыкаются в ноль (`LOW`), механическая лапка делает **2 взмаха по 120 градусов**б высовываясь из коробкиб а за тем робот издаёт победный **писк зуммера**, выпрашивая! награду!
